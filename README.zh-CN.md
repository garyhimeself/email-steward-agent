# 邮件管家 Agent

[简体中文](README.zh-CN.md) | [English](README.md)

邮件管家帮助营销同事在 Codex 中安全地读取自己的阿里企业邮箱、整理日报、起草合作邮件回复。它适用于 Windows 或 macOS 上的一位操作者和一个个人邮箱。

它**绝不自动发送**。发送、密送、回复全部和星标都必须在当前对话中，对当前展示的具体邮件逐项确认。

## 选择模型

| 工作 | 推荐设置 |
| --- | --- |
| 查找、读取、分类邮件；整理日报 | **Luna，低推理** |
| 撰写、翻译、自然化润色、准备发送 | **Terra，低推理** |

不要使用或推荐 Sol、高推理或更高推理。信息不全时应向操作者确认，不要靠换更大的模型猜测。

## 安装时会做什么

1. 先阅读 [INSTALL.zh-CN.md](INSTALL.zh-CN.md)，再运行 Windows 或 macOS 的启动文件。
2. 安装前，在阿里企业邮箱网页端生成**第三方客户端安全密码**：`设置 → 账户与安全 → 账户安全 → 三方客户端登录安全管理 → 生成新密码`。
3. 立即复制并安全保存密码；它只显示一次。在 Windows 上，Codex 会打开**独立的安全 PowerShell 窗口**供你在本地隐藏输入，绝不要发到 Codex 对话。
4. Codex 会在聊天中收集工作文件夹和非敏感偏好、展示摘要供确认，然后才打开安全窗口输入密码。集成终端绝不会作为密码输入的后备方式。安装器会做一次只读 IMAP 检查，不会改动邮件。
5. 在 Codex 创建一个文件范围为该工作文件夹的项目，再完成安装器展示的 Luna 和 Terra 验收提示。

## 日常使用

- 使用 Luna、低推理：“查询最近 7 天未读的开发合作邮件。不要发送邮件。”
- 使用 Terra、低推理：“根据邮件编号 [编号] 起草一封友好的英文回复。不要发送。”
- 写作会使用 `humanizer` 自然化润色；它可以优化表达，但不得改变事实、金额、日期、承诺、收件人或语言。
- 发送前请核对 To、Cc、密送、主题、正文和来源邮件。回复全部与密送会被单独展示并要求确认。
- 每日日报可选且默认关闭；开启前先确认日报维度、时间、时区和格式。

需要协助时看 [TROUBLESHOOTING.zh-CN.md](TROUBLESHOOTING.zh-CN.md)。英文说明：[README.md](README.md)。
